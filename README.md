# MyTop Linux

Linux-версия Android-приложения «Мой топ». Приложение написано на Rust, работает
офлайн и хранит коллекцию в SQLite. Интерфейс использует GTK/WebKitGTK и повторяет
Material 3-компоновку мобильной версии.

## Архитектура

Код разделён по направлению зависимостей: внешние адаптеры зависят от сценариев,
а сценарии — от доменной модели. Домен не знает о GTK, WebKitGTK или SQLite.

```text
src/
├── domain/          # Game, Query, оформление и правила валидации
├── application/     # сценарии коллекции, импорт/экспорт и порты репозиториев
├── infrastructure/  # реализация портов в SQLite
├── presentation/    # desktop-адаптер GTK/WebKitGTK и IPC
├── error.rs         # общий тип результата
├── lib.rs           # публичный фасад библиотеки
└── main.rs          # composition root и запуск приложения
```

`GameRepository` и `SettingsRepository` принадлежат application-слою. Благодаря
этому хранилище можно заменить без изменений домена и пользовательских сценариев.

Поддерживаются:

- добавление, редактирование, просмотр и удаление игр;
- поиск, пять сортировок и совместные фильтры;
- все поля игры, обложки и даты прохождений;
- совместимый с Android импорт и экспорт JSON, экспорт TXT и буфер обмена;
- светлая, тёмная и системная темы, акцент, шрифты, масштаб текста, скругления и
  компактные карточки;
- 13 языков из исходного Android-приложения;
- сохранение настроек синхронизации с тем же безопасным поведением заглушки:
  сеть не используется, пока серверный адаптер не реализован.

## Запуск

```sh
cd /home/popov/MyProject/MyTopLinux
nix run path:.
```

Данные сохраняются в `$XDG_DATA_HOME/mytop-linux` или
`$HOME/.local/share/mytop-linux`.

## Временное окружение разработки

```sh
cd /home/popov/MyProject/MyTopLinux
nix develop path:.
cargo run
```

Проверки:

```sh
cargo test
cargo clippy --all-targets -- -D warnings
```

Сборка устанавливаемого Nix-пакета:

```sh
nix build path:.
./result/bin/mytop-linux
```

Для переноса существующей коллекции экспортируйте JSON в Android-приложении и
откройте его через меню `⋮ → Импорт JSON` в Linux-версии.
